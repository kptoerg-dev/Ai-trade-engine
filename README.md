# AI Trading Engine v12

Research-grade Streamlit trading research engine.

## Included
- `app.py` — Streamlit GUI
- `ai_trading_engine.py` — ML, walk-forward and backtest engine
- `requirements.txt` — dependencies
- `.gitignore`
- `.streamlit/config.toml`

## GitHub / Streamlit Cloud
Upload all files to the repository root. The Streamlit entry point is `app.py`.

## Important
This project is for research and educational purposes. Backtests are not guarantees of future returns. Always test with realistic costs, out-of-sample data and stress scenarios before considering live use.
